The second release candidate of Tidash 1.0. It changes nothing in the app: it exists so that every 1.0.0-rc.1 install can test self-update.

## Testing the update

With 1.0.0-rc.1 installed (the Windows installer or zip, the macOS app in Applications, or the Linux tar.gz):

1. Open Settings › Updates and choose Check now, or wait for the check at start.
2. Tidash downloads 1.0.0-rc.2 in the background and shows Restart to update.
3. After the restart, Settings › Updates says Tidash 1.0.0-rc.2.

A deb, rpm or AppImage install does not update itself: Settings says so, and the new package is on this page.

Everything else is as in [1.0.0-rc.1](https://github.com/rojnwa/tidash/releases/tag/v1.0.0-rc.1), including its known limitations.
